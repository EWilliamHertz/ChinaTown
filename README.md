# CT-Global Modular Solutions

Project CT-China Town: A 'Smart Town as a Service' venture based on Hatake Hugo's concept. This repo manages the logistics, IoT, and software for deploying scalable 'Lego-like' modular communities with integrated 4K surveillance and smart grids.

## 🚀 Features

### Multi-Page Architecture
- **Separate HTML pages** for each section for better organization and maintainability
- **Organized CSS and JS** in dedicated folders
- **Clean navigation** with mobile-responsive menu
- **All citations removed** for professional presentation

3. **Our Solution** - Product offerings and Smart Town technology
4. **The Market** - Market analysis and opportunities

## 📝 How to Update the Journal

See the detailed guide in [JOURNAL_UPDATE_GUIDE.md](JOURNAL_UPDATE_GUIDE.md)

**Quick Steps:**
1. Open `journal.html` in a text editor
2. Copy an existing journal entry block
3. Paste it at the top of the entries section
4. Update the date, category, title, and content
5. Save and push to GitHub

## 🔧 Development

### Technologies Used
- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework (via CDN)
- **Vanilla JavaScript** - No framework dependencies
- **GitHub Pages** - Static site hosting

### Making Changes

1. **Clone the repository:**
   ```bash
   git clone https://github.com/EWilliamHertz/ChinaTown.git
   cd ChinaTown
   ```

2. **Make your changes** to the HTML, CSS, or JS files

3. **Test locally** by opening `index.html` in a browser

4. **Commit and push:**
   ```bash
   git add .
   git commit -m "Your commit message"
   git push origin main
   ```

5. **Wait 1-2 minutes** for GitHub Pages to rebuild
